# 🎮 Tic-Tac-Toe (Python)

![Python](https://img.shields.io/badge/python-3.x-blue.svg)


## 📖 Description
A command-line Tic-Tac-Toe game in Python where a human 
player competes against a computer opponent with random moves.

## ⚙️ Installation
```bash
git clone https://github.com/BoniYu/tic-tac-toe.git
cd tic-tac-toe
python main.py
```

## 🕹️ How to Play
1. Run the script
2. Choose **X** or **O**
3. Game randomly decides who goes first
4. Enter a number **(1–9)** to place your mark:
